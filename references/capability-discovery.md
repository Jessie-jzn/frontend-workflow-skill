# 能力发现与本地学习

## 当前任务的最小搜索

先查询已初始化项目的私有能力卡片：

```bash
node <skill-dir>/scripts/profile.mjs list --project <root> --json
```

然后用 `rg` 搜索组件名、交互术语、API 字段、事件、import、模板标签和公共目录。通常只读取 1～3 个候选和一个真实调用方；只有修改公共能力或多个方案同等合理时，才枚举全部调用方。

## 选择规则

按“直接复用 → 组合 → 兼容扩展 → 局部实现 → 新组件”选择。已有能力不完全匹配且必须迁移旧调用方才能复用时，放弃这条路线，除非用户明确授权重构。

## Profile

初始化只写 Git worktree 外的私有目录：

```bash
node <skill-dir>/scripts/init.mjs --project <root>
```

卡片只保存名称、路径、用途、输入输出摘要、证据和指纹。读过且有证据的能力可记为 `candidate`；用户明确指定的能力为 `confirmed`。文件变化后仅在当前任务需要时验证和重读。

至少两个契约一致的真实调用方、稳定路径和明确长期价值同时满足时，才在任务结束时建议用户提升。绝不自动提升、写入项目、写入 Git 或保存源码/响应/密钥。
