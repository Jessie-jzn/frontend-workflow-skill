# 提交前检查

先运行只读变更检查：

```bash
node <skill-dir>/scripts/check-changed-files.mjs --project <root>
```

它会列出变更、前端文件、公共风险候选、diff 空白问题和已存在脚本的建议命令；不会执行 lint、测试或构建。

## 按风险扩大

- JS/TS/Vue/Svelte：使用项目现有的定向 lint 或类型检查，绝不盲目运行带 `--fix` 的全仓命令。
- 路由、权限、请求、状态、公共组件、hooks、utils、样式：枚举调用方并扩大回归。
- UI：检查目标状态、权限组合、主交互、窄屏和溢出。
- 构建会生成产物时，执行前确认范围；完成后检查产物未误入交付。
- 接口功能：用确认过的真实样例覆盖成功、失败、空值和刷新；无法联调时明确未验证项。

交付中说明实际运行命令及结果、验证的行为、未做事项和准确原因，以及公共调用方覆盖和残余风险。
